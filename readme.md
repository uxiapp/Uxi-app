## Servers

Anyways, have fun with the servers or create some of your own!

Want to promote your own server? You can put your server link in Issues. Someone would probably find them.

**Server Issues are for promoting your servers, NOT reporting servers for bad content.**

Also, don't just create like a lot of server issues. Post your server link in the comments of someone else's server issue instead. Or you can create a server list. Check in app for how it’s formatted the list. Also the server list must only contain that. No fancy HTML with the server list

### Server Warnings

If you think a server is bad, you can create an issue using the server warning template so less people end up joining it.

BUT you MUST include an image or some kind of proof showing that the server is actually doing what you say it is. Don't just make stuff up.

If the server has very bad content and you take a screenshot of it while it's happening, FIRST OFF, BLUR IT. We don't want people getting banned off GitHub just for reporting a server.
